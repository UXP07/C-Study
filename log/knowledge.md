# 知识点清单

C 语言学习主线：C 核心 → 内存与高级专题 → 工具链 → 操作系统 → 网络 → 高性能与内核深入，共 **53** 个知识点；附录 A/B 为方向目录与常用库速览（不占编号、不设状态）。

- **排序**：波次之间由浅入深；同一波次内大致有序，可按需并行
- **状态**：`未学习` → `学习中`（出题后自动改）→ `已学习（日期）`（用户确认后才改）
- **出题**：对 Claude 说"按 N 号出 M 道题"；验收后说"把 N 号标为已学习"
- **环境标注**：`[Linux]` 动手需 WSL2/虚拟机（fork/信号/mmap/epoll 等）；`[GPU]` 需 NVIDIA GPU（无卡时以概念/源码阅读替代）；未标注 = 本机 MinGW 可动手（#26 pthread 本机亦可跑）。环境不可用时出概念/代码阅读/设计题替代
- **语言标准**：C11（gcc 8.1 完整支持）
